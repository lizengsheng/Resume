# 实施计划

## 批次一：项目基础

- 范围：引入上游模板、建立独立仓库、项目记忆和基础配置。
- 风险：低。
- 最小验证：确认目录结构、许可和 Git 分支。
- 独立审查：不需要，实现者自检。

## 批次二：内容与页面

- 范围：中文首页、内容集合、两个项目详情、主题和响应式视觉。
- 风险：中。
- 最小验证：类型检查、生产构建和关键路由检查。
- 独立审查：最终里程碑统一综合审查，不单独重复审查。

## 批次三：公开简历

- 范围：提取证件照、生成不含手机号的一页 PDF，并接入下载。
- 风险：中（隐私和版式）。
- 最小验证：全文隐私扫描、PDF 文本抽取和逐页渲染检查。
- 独立审查：不需要，使用确定性隐私检查和视觉 QA。

## 批次四：部署与验收

- 范围：GitHub Pages 工作流、README、完整构建、桌面/移动端与路径检查。
- 风险：中。
- 最小验证：完整生产构建、构建产物扫描、关键页面视觉检查。
- 独立审查：实施者做一次综合自审。

## 批次五：通用模板重构

- 范围：参考站式首页骨架、集中个人配置、可直接替换头像、通用项目 Schema、全部项目页和维护说明。
- 风险：中（首页信息架构与内容接口变化）。
- 最小验证：类型检查、生产构建、项目增删兼容检查、桌面/手机标签交互与布局检查、隐私及 `/Resume` 路径扫描。
- 独立审查：实施者在里程碑结束时做一次综合自审，不重复启动独立审查。

## 批次六：远程发布

- 范围：创建公开 GitHub 仓库、建立远程、推送 `main`、启用 GitHub Actions Pages，并验证线上首页和关键资源。
- 风险：中（外部公开发布与仓库设置变更）。
- 最小验证：公开文件隐私扫描、远程分支检查、Actions 运行结果、Pages API 状态及线上 HTTP/页面内容检查。
- 独立审查：不需要；沿用已通过的最终构建证据，并对远程状态做一次综合验证。
