# 实施计划

## 批次一：项目基础

- 范围：引入上游模板、建立独立仓库、项目记忆和基础配置。
- 风险：低。
- 最小验证：确认目录结构、许可和 Git 分支。
- 独立审查：不需要，实现者自检。

## 批次二：内容与页面

- 范围：中文首页、内容集合、两个项目详情、主题和响应式视觉。
- 风险：中。
- 最小验证：类型检查、生产构建和关键路由检查。
- 独立审查：最终里程碑统一综合审查，不单独重复审查。

## 批次三：公开简历

- 范围：提取证件照、生成不含手机号的一页 PDF，并接入下载。
- 风险：中（隐私和版式）。
- 最小验证：全文隐私扫描、PDF 文本抽取和逐页渲染检查。
- 独立审查：不需要，使用确定性隐私检查和视觉 QA。

## 批次四：部署与验收

- 范围：GitHub Pages 工作流、README、完整构建、桌面/移动端与路径检查。
- 风险：中。
- 最小验证：完整生产构建、构建产物扫描、关键页面视觉检查。
- 独立审查：实施者做一次综合自审。

## 批次五：通用模板重构

- 范围：参考站式首页骨架、集中个人配置、可直接替换头像、通用项目 Schema、全部项目页和维护说明。
- 风险：中（首页信息架构与内容接口变化）。
- 最小验证：类型检查、生产构建、项目增删兼容检查、桌面/手机标签交互与布局检查、隐私及 `/Resume` 路径扫描。
- 独立审查：实施者在里程碑结束时做一次综合自审，不重复启动独立审查。

## 批次六：远程发布

- 范围：创建公开 GitHub 仓库、建立远程、推送 `main`、启用 GitHub Actions Pages，并验证线上首页和关键资源。
- 风险：中（外部公开发布与仓库设置变更）。
- 最小验证：公开文件隐私扫描、远程分支检查、Actions 运行结果、Pages API 状态及线上 HTTP/页面内容检查。
- 独立审查：不需要；沿用已通过的最终构建证据，并对远程状态做一次综合验证。

## 批次七：可持续内容更新

- 范围：英文展示名、自动项目计数、项目模板、更新与发布指南、可复用线上链接检查和 Pages 部署后校验。
- 风险：中（公开身份显示、自动部署门禁和外部链接验证）。
- 最小验证：类型检查、生产构建、文本扫描、线上全链接检查、Actions 成功和本地/远端提交一致。
- 独立审查：不需要；实施者完成一次综合审查和线上验证。

## 批次八：依赖与兼容升级

- 范围：升级 Astro 7、收敛依赖、修复安全审计项与移动端项目封面。
- 风险：中（框架大版本与内容接口兼容）。
- 最小验证：依赖审计、类型检查、生产构建、最小字段 Markdown 项目测试和线上发布。
- 独立审查：不需要；实施者完成一次综合兼容性检查。

## 批次九：博客同源视觉统一

- 范围：以在线博客为视觉基准统一设计令牌、窄栏导航、连续首页、项目卡与 Markdown 正文样式，同时保留作品集的信息架构和内容接口。
- 风险：中（跨公共样式与响应式页面的视觉重构，不改变 Schema、路由或依赖架构）。
- 最小验证：依赖审计、Astro 检查、生产构建、最小字段 Markdown 项目测试、桌面与 390px 明暗主题检查、无脚本静态内容检查、严格链接检查和线上 Pages 验证。
- 独立审查：按用户计划不启动重复审查代理，由实施者完成一次综合视觉与生产审查。

## 批次十：标签页与操作层级优化

- 范围：精简导航品牌和首屏按钮，统一功能图标与字体尺寸，在博客同源视觉下恢复“项目 / 关于”渐进增强标签页。
- 风险：中（首页交互、URL 锚点、键盘行为和响应式样式变化，不改变内容 Schema 或公开路由）。
- 最小验证：依赖审计、Astro 检查、生产构建、最小字段 Markdown 测试、标签键盘与锚点检查、无脚本内容检查、桌面/手机明暗主题和严格链接验证。
- 独立审查：按用户计划不启动重复审查代理，由实施者完成一次综合交互与视觉审查。
